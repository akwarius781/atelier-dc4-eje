# Atelier DC4 EJE – Devoir sur table

Application d'atelier pour les étudiants éducateurs de jeunes enfants (3e année) : 9 critères, gestion des 4 heures, propositions intra / inter / extra-institutionnelles, générateur QQOQCP.

- Fonctionne sur ordinateur, tablette et téléphone.
- Installable comme une application (« Ajouter à l'écran d'accueil »), utilisable hors ligne.
- La progression de chaque étudiant reste enregistrée dans son navigateur.

Mise à jour : modifier `index.html`, puis pousser sur `main` ; GitHub Pages republie le site en une minute environ.
